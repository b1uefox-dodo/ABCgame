## 📖 项目简介 (Introduction)

传统的打字或识字软件对于 3~5 岁的幼儿来说过于单一枯燥。**《奇趣键盘大冒险》** 将电脑键盘打造成一个充满奇迹的魔法玩具箱！

每一次敲击按键，屏幕都会即时呈现富有弹性的拟人物体、清脆悦耳的木琴音阶与纯正的双语发音。游戏内置 5 大玩法模式、14 款隐藏全屏魔法彩蛋与 5 大奇幻世界主题，让宝宝在自发探索中建立对字母、数字、英语自然拼读与键盘方位的认知。

## ✨ 核心特色与玩法 (Key Features)

### 1. 🌟 自由探索宇宙 (Free Playground)
- **字母直读认知 (A-Z)**：敲击任意字母，屏幕掉落对应拟人角色，伴随纯正直读发音（`A` 对应 🍎 苹果、👨‍🚀 宇航员、🐊 鳄鱼、✈️ 飞机）。
- **单键连击变化**：同一个字母多次敲击会自动轮播 2~4 款不同趣味形态！
- **数字数感阶梯 (0-9)**：按下数字，空中掉落对应数量的跳跳小动物（按 5 掉落 5 只小鸭），同时奏响 Do-Re-Mi 音乐音阶！
- **60FPS 物理引擎**：所有物体均具备重力加速度、反弹力与摩擦力，可用鼠标/手指拖拽、抛掷、碰撞。
- **神奇功能键玩法**：
  - `Space` 空格键：发射彩虹礼炮与全屏狂欢！🎉
  - `Enter` 回车键：召唤神秘惊喜盲盒，点击开箱蹦出超萌跳舞角色！🎁
  - `Backspace` 退格键：萌萌“咕噜吸尘怪兽”出动清屏！🌪️
  - `↑ ↓ ← →` 方向键：控制画面中的吉祥物萌宠（小恐龙、星宝熊等）跑跳翻滚！

### 2. 🎈 气球寻宝大作战 (Balloon Pop Quest)
- 七彩气球载着字母与数字徐徐升空。
- 语音与插画双重引导，敲击对应按键发射金色飞镖击破目标气球，赢取连击奖励！

### 3. 🚂 数字小火车 (Number Train Adventure)
- 嘟嘟嘟！动物小火车进站啦！
- 按数字键 1-5 为车厢依次装载对应数量的新鲜水果（1号车装1个苹果，2号车装2根香蕉...），装满后鸣笛启程！

### 4. 🧩 魔法单词拼图 (Word Magic Builder)
- 展示生动插画与缺失字母的单词卡片（如 `C _ T`、`D _ G`、`S _ N`、`C _ R`）。
- 按下缺少的字母，激活全屏拼词变身魔法秀！

### 5. 🎹 动物音乐节拍 (Animal Music Band)
- 数字键 1～8 化身彩虹音乐钢琴琴键！
- 支持切换 6 种萌趣音色：木琴 🪗、小猫叫 🐱、小鸭嘎嘎 🦆、青蛙呱呱 🐸、竖琴 🎶、鼓点 🥁。
- 内置《小星星》、《两只老虎》、《新年好》简谱跟弹指南！

## 🎁 隐藏拼词大彩蛋 (14 Easter Eggs)

尝试在键盘上连续敲击以下英文单词，即可解锁全屏电影级动画变身秀：
- `CAT` (小猫咪狂欢) • `DOG` (小狗狗接飞盘) • `SUN` (太阳公公升起) • `CAR` (极速赛车冲锋)
- `BUS` (彩虹大巴士) • `PIG` (快乐小猪踩水坑) • `FOX` (魔法小狐狸) • `BEE` (勤劳小蜜蜂)
- `FLY` (展翅高飞) • `STAR` (璀璨流星雨) • `FISH` (梦幻神仙鱼) • `LOVE` (爱心风暴)
- `RAIN` (糖果彩虹雨) • `ICE` (晶莹冰雪魔法)

## 🌐 三语种发音与音频引擎

内置 **110+ 款 AAC 本地高保真原声音频**，杜绝浏览器沙盒与网络 TTS 权限拦截：
- 🌐 **双语模式 (Bilingual)**：*“A，Apple，苹果！”* / *“5，Five，五，5 颗金星星！”*
- 🇺🇸 **纯英文模式 (English)**：*“A, Apple!”* / *“5, Five!”*
- 🇨🇳 **纯中文模式 (Chinese)**：*“A，苹果！”* / *“5，五，5 颗金星星！”*
- **即时缓存机制**：基于 `AudioCache` 内存对象池，敲键 0 毫秒极速发声。

## 🚀 快速开始 (Getting Started)

### 环境依赖
- [Node.js](https://nodejs.org/) (v18.0 或更高版本)
- [npm](https://www.npmjs.com/) 或 [pnpm](https://pnpm.io/)

### 安装与启动
```bash
# 1. 克隆代码仓库
git clone https://github.com/b1uefox-dodo/ABCgame.git
cd ABCgame

# 2. 安装依赖
npm install

# 3. 启动本地开发服务 (支持热重载)
npm run dev

# 4. 构建生产发布包
npm run build

# 5. 启动生产预览服务
npm run preview
```
启动后在浏览器中打开 `http://localhost:4173/` 即可开始探索！

### 🖥️ macOS 一键桌面快捷方式
项目内置了由 `osacompile` 编译的 macOS 原生应用程序与启动脚本：
- 直接双击桌面上的 **`奇趣键盘大冒险.app`**（带专属彩虹 3D 键帽图标），系统将自动在后台拉起轻量服务并在浏览器中进入全屏游戏。
- 游戏中点击右上角“退出”按钮，将通过本地 `/api/exit` 接口完整终止后台进程，不占用系统资源。

## 🌐 English Introduction

**KeyMagic Adventure** is an open-source educational keyboard playground designed specifically for children aged 3 to 5 years old. 

Instead of traditional, boring drilling cards, it turns the computer keyboard into an exciting, reactive world full of bouncy physics entities, cheerful xylophone chords, and clear bilingual voice pronuncation.

### Key Highlights
- **5 Engaging Modes**: Free Playground, Balloon Pop Quest, Number Train, Word Magic Builder, Animal Piano Band.
- **14 Easter Egg Words**: Typing `CAT`, `DOG`, `SUN`, `CAR`, `BUS`... triggers full-screen celebratory animation.
- **Triple Language Support**: Toggle between Bilingual, Pure English, and Pure Chinese voice feedback on the fly.
- **Zero-Latency Audio**: Built-in 110+ high fidelity AAC native audio clips without dependency on fragile browser TTS APIs.
